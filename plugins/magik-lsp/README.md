# magik-lsp

Magik language server for Claude Code, providing code intelligence.

## Supported Extensions
`.magik`

## Installation

### Manual Installation
1. Download from [Magik-tools releases](https://github.com/StevenLooman/magik-tools/releases)
2. Extract to a directory (e.g., `~/.local/share/magik-lsp`)
3. Create a wrapper script named `magik-lsp` in your PATH

## Requirements
- Java 17 or later (JDK, not just JRE)
